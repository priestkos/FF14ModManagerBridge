FF14 Mod Manager Bridge (framework thread)
  1. validate collection, dir, enabled
  2. Penumbra TrySetMod(collection, dir, enabled)
  3. Success or NothingChanged counts as done
  4. logged in → Penumbra RedrawObject(0, Redraw) on you
  5. reply {ok}
Only the mod you name is touched, in the collection you name. The redraw is skipped at the title screen.
